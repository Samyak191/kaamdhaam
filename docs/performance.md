# Performance review

Measured with Vite production build on Windows on 23 November 2026. Before Sprint 3, the largest `index` chunk was **661.33 kB raw / 189.11 kB gzip**, and Vite warned about a >500 kB chunk. After lazy loading the live app and grouping live pages by route area, the final `index` chunk is **247.66 kB raw / 77.91 kB gzip**. The live app entry is a separate **251.42 kB raw / 66.05 kB gzip** chunk, loaded only in live mode; route page groups load later. The 500 kB warning is gone. These are bundle sizes, not measured page load times; live mode loads both entry chunks and lazy routes add follow-up requests when first opened.

The live route groups are discovery, account, projects, contracts and activity. Demo routes remain lazy. The original CSS and visual identity were not redesigned. `useData` now ignores stale responses after a route key changes or unmounts; live routes remount when the authenticated user changes. Messages and notifications continue polling only while the tab is visible, with bounded pages and explicit read actions.

Database review: public jobs, freelancers, proposals, contracts, messages and notifications have bounded pages. Messages use a stable sequence cursor. Other lists use bounded offsets (up to 10,000), deterministic ordering in most paths, and appropriate existing indexes for status, participants and unread notifications. No N+1 loop was found in the main listings; conversation unread counts are batched. Contract listings currently include all milestone submission history, increasing response size over long projects. Existing local data is too small to justify a new index or search infrastructure from timings alone. PostgreSQL substring search may need `pg_trgm` or full-text indexes after an `EXPLAIN (ANALYZE, BUFFERS)` on representative production-scale data. No speculative migration was added.

`node scripts/load-smoke.mjs` performs 40 requests each to health, jobs and freelancers, concurrency 4, and refuses non-loopback targets. It never calls hosted Supabase. Against the isolated empty Docker database through Nginx on 23 November 2026, health measured **187.1 req/s, p50 9.0 ms, p95 45.5 ms**; jobs **190.2 req/s, p50 18.4 ms, p95 55.1 ms**; freelancers **127.7 req/s, p50 27.7 ms, p95 58.7 ms**; all 120 requests returned successfully. These are short laptop measurements with an empty database, not EC2 capacity guarantees or realistic marketplace traffic.
